## [0.1.0] - 2026-07-05

### Added
- Single-file, dependency-free static portfolio site (`index.html`) for Satya Sai Prakash Kantamani, Gen AI Engineer & Data Scientist, deployed via GitHub Pages at https://kantamaniprakash.github.io.
- Samurai/Japanese-inspired visual redesign with hand-written HTML and CSS, 3D depth animations, and an aurora background.
- Interactive About section featuring dynamic rotating impact stats that cycle every few seconds.
- Featured project showcase with filter tabs and deep-dive detail modals, including the Supply Chain Disruption Intelligence project.
- Playful interactive touches: an Easter-egg terminal, Konami-code trigger, animated skill bars, and a copy-email toast.
- Continuous integration workflow that validates `index.html` with html-validate on every push and pull request.
- Automated GitHub Actions dependency updates via Dependabot, plus MIT license, README, and `.gitignore`.
