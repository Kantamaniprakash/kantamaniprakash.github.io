## Local preview

The site is a single static file (`index.html`) with no build step. You can open it directly:

```bash
# Option 1 — open the file in your browser
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux
```

Or serve it over HTTP for behavior closer to production:

```bash
# Option 2 — Python's built-in server (http://localhost:8000)
python -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

## Deployment

This repository is a GitHub Pages **user site**. Any push to the `master` branch is automatically published to https://kantamaniprakash.github.io — no build or CI step is required.
